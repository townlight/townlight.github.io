Inside the repository

What the Library foundation contains

Staff drafts

Draft policy answers, program replies and reference suggestions that librarians verify before use.

Collection metadata

Search collection metadata and prepare collection-development guidance without patron records.

Optional workpapers

Save program and collection workpapers in an optional local database.

Current status

Parked, and outside the released suite.

Townlight Library is a parked foundation. It is not a completed Townlight product, and the Townlight Windows release does not install or support it. Examples and package names in the repository describe the foundation. Do not use them as suite installation instructions.

  • Released Windows suite, current modules and limits
  • Current Townlight products

What it does not do

Patron records are out of scope. It does not integrate with a library system, replace professional reference service, provide legal advice or call live language models.
