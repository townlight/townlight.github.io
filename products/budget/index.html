Inside the repository

What the Budget foundation contains

Drafting helpers

Prepare line-item variance notes, department narratives and council-facing memos.

Hearing and resident material

Build hearing packet checklists and plain-English resident summaries.

Optional workpapers

Save workpaper records in an optional local database, with role-protected retrieval.

Current status

Parked, and outside the released suite.

Townlight Budget is a parked foundation. It is not a completed Townlight product, and the Townlight Windows release does not install or support it. Examples and package names in the repository describe the foundation. Do not use them as suite installation instructions.

  • Released Windows suite, current modules and limits
  • Current Townlight products

What it does not do

Finance staff approve every number, narrative, public summary and packet item. It provides no ERP, accounting, payroll, budget adoption, official approvals, live language model calls or live finance connector.
