Current status

Parked, and outside the released suite.

Townlight Data is a parked foundation. It is not a completed Townlight product, and the Townlight Windows release does not install or support it. Examples and package names in the repository describe the foundation. Do not use them as suite installation instructions.

  • Released Windows suite, current modules and limits
  • Current Townlight products

What it does not do

Every dataset still needs human review, license confirmation, redaction or exemption clearance, and retention checks. It provides no live CKAN publication, dashboard, data warehouse, autonomous redaction or connector.
